# cc-clinic-lab · 临床试验访视采集台

数据工程产品线基线。题号前缀 `clinic-*`，默认端口 **7600**。

## 技术栈

- 后端：CherryPy + SQLite
- 前端：原生 JS SPA（顶栏薄荷绿丝带导航）
- 会话：itsdangerous 签名 Cookie
- 测试：pytest + httpx（依赖已列入 requirements）

## 登录

- 地址：`http://127.0.0.1:7600/login`
- 账号：`admin` / `123456`

## 页面

| 页面 | 能力 |
|------|------|
| 试验中心 | 中心登记、启停/观察、配额、配额闸摘要与落点、方案版本生效 |
| 访视批次 | 开批、模拟抓取、追加访视行、合格入库、收齐/关闭（均过配额闸） |
| 字段质控 | 按批/全量扫描、发现关闭/重开 |
| 缺口补采 | 排队、执行成功/失败、失败重试 |
| 访视对账 | 缺口/发现/补采对照、中心矩阵（配额徽标/已用/落点）、审计 |
| 台参数 | 设置读写、配额闸口径 |

## 配额闸

试验中心配额已满时，抓取仍会灌满质控与补采队列。配额闸负责在写侧拦下超额抓取。

- 落地形态：**甲侧旁路凭证 + 指纹链**（`app/services/quota_gate.py`）。
- 写侧：开批 / 抓取 / 追加统一过闸，`BEGIN IMMEDIATE` 串行化；抓取整批预占，剩余不足即整笔拦截并整笔回滚。
- 落点：每次过闸写 `quota_ledger` 一条凭证，附 HMAC 指纹并与同中心上一条成链，随后立即复核封存。
- 读侧：只认本条凭证；`gate_key` 唯一，重复提交判回刷并拒绝；指纹或链对不齐即驳回。
- 徽标对账：列表展示「配额徽标」（批次计数器汇总）与「已用配额」（实时访视行）；两者拧花即拦截本次抓取。
- 详情页给白话原因：中心、已用/配额、剩余、本次需要、尚缺。

败例清单见 `docs/quota-gate-cases.md`。

## 主链

中心 → 访视批次抓取（过配额闸） → 质控发现 → 缺口补采 → 对账报告；设置与审计贯穿写操作。

## 本地
